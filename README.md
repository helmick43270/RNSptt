This is an Android Studio project being built for an Android 5.1.1 PoC radio (API level 22), the UNIPRO ZX (KSUN ZL10, HamGeek HG-369, Vtesping B5, YiNiTone B5, Anysecu T56, etc.) It aims to make the radio a native Reticulum node with LXST/LXMF interoperability with other Reticulum-based apps, specifically with respect to PTT voice. So far, it's just a Hello World program that starts a Rust-based binary which is a Reticulum TCP server, with code from https://github.com/BeechatNetworkSystemsLtd/Reticulum-rs/tree/main, compiled for armv7. Hard-coded in the server binary is its IP address, 0.0.0.0:4242. If anyone is interested in tinkering, I highly recommend cloning the Beechat repo, building one of their examples to the armv7-androideabi target (API 22), dropping it into the app/src/main/assets folder in this project, and then updating the RustBinaryService.kt file to open your binary. The RustBinaryService starts the named binary under another process which will stay running if you back out of the app, but will stop if you shut the app down.

This project's focus is centered tightly around the above-mentioned legacy PoC network radios, because there is already plenty of Reticulum functionality out there for modern platforms.
